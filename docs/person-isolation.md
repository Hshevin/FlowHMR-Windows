# 逐人分割隔离（实验）

在「人物检测与隔离」中选择 **YOLO26 · 逐人分割隔离**，保留「手动选人」开启，上传视频后勾选一人或多人。每个人独立排队生成动作，完成后沿用现有多人场景对齐、角色预览和 FBX / NPZ / VMD 导出流程。默认仍为 YOLOX。

## 安装

在项目目录，通过 uv 将可选依赖装入**实际运行推理的 Python 环境**，然后重启程序：

```bash
uv pip install --python /path/to/inference/python -r requirements-isolation.txt
```

源码虚拟环境可使用 `.venv/bin/python`（Windows 为 `.venv\Scripts\python.exe`）。Windows 便携版应指定当前选中推理环境的 `python.exe`，不要误装入其他 Python。此可选依赖尚未包含在便携版基础包里。安装时保留该环境原有的 PyTorch / TorchVision GPU 版本。

首次使用会由 Ultralytics 下载 `yolo26l-seg.pt` 和 `yolo26n-cls.pt`，保存到 `models/person_isolation/`。离线使用前可自行把这两个官方权重放在该目录。新模式不加载或要求 YOLOX 权重，仍需要原有的身体、动作和相机模型。

## 工作方式

- 参考 [MIRAI](https://github.com/Hshevin/MIRAI) 的选中人物保持清晰、其他画面模糊的思路；独立实现集成，没有复制其源代码。
- YOLO26-L 实例分割产生每个人的轮廓；BoT-SORT 使用运动、相机运动补偿和外观特征关联人物。外观编码使用 YOLO26 分类模型。这与 MIRAI 的 BoxMOT / OSNet 实现不同，也未接入 MIRAI 的 SAM 2 手动提示修正。
- 检测时同时保存人物 ID 和掩码轮廓，子任务复用同一份只读掩码缓存，不在隔离阶段重新按检测框匹配人物。
- 逐人保留掩码内的原始画面，模糊其他人物和背景。两个掩码冲突的像素保持模糊；缺失的掩码不使用矩形框或旧掩码替代。
- 隔离视频保持原始尺寸、30 FPS 和源帧编号。身体特征、手框和 HaMeR 精修使用该视频。相机估计和原片预览继续使用原视频；多人站位观测也应用对应人物的掩码。
- 切换检测模式会重新检测和选人，并使相关特征缓存失效。更改时间范围也会重新生成隔离输入。任务卡显示没有有效掩码的帧数；多人任务累计各人的帧数。

## 效果边界

这里的“反模糊”是从原片保留目标人物像素，不是去模糊或补全模型。遮挡期间缺失的肢体仍由动捕模型估计。外观相近、长时间完全遮挡、出画再入画仍可能换 ID 或断轨；同一个人可能出现多个候选轨迹。模糊背景也可能降低身体特征质量，效果需要同一素材与 YOLOX 对比确认，不承诺精度提升。

分割和外观匹配增加推理时间及显存占用，隔离视频增加磁盘占用。暂未做真实 GPU 多人素材的端到端精度评估。可选 Ultralytics 软件和权重遵循其自身许可，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
